About the Project

This project is a MySQL database for Crownfield Eye Hospital. I worked in a group of three students to create a database with 10 related tables and sample data.

The database stores information about patients, clinicians, clinics, appointments, diagnoses, prescriptions, medicines and follow-up care.

My Individual Work

As Student 2, I was responsible for the Clinic and Appointment tables.

I created and tested six SQL features:

GROUP BY and HAVING

INNER JOIN

LEFT JOIN

Subquery

Stored procedure

Trigger

I also worked on the Receptionist and Patient roles and tested database validation, hashing and transactions.

Project Files

Crownfield_Group_Database.sql – the shared database with 10 related tables and sample data.

Student2_Individual_SQL.sql – my six SQL features, stored procedure, trigger, Receptionist and Patient roles, hashing demonstration and transaction tests.

05_ERD_Ready_For_GitHub.drawio – an editable ER diagram showing the 10 tables and their relationships.

How to Use

First, open MySQL Workbench and run Crownfield_Group_Database.sql to create the database and insert the sample data.

Then run Student2_Individual_SQL.sql to execute my individual SQL queries, stored procedure, trigger and tests.

The ER diagram can be opened and edited using diagrams.net.

Some SQL tests are commented out because they are expected to produce errors. They can be run separately to check that the database rules work correctly.

The role commands may require an account with permission to create roles and grant access.

Conclusion

This project helped me understand how relational databases work and how SQL can be used to manage hospital information. I also learned more about database relationships, validation, user permissions and transactions.
